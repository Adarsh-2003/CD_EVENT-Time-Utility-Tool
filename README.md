# CD_EVENT Time Utility Tool

Minimal web page that displays a fixed statement plus a **real-time timestamp in New York time** (`America/New_York`) and provides a **Copy** button to copy the entire message.

## Run

- Open `index.html` in your browser (double-click it).

## Output format

Copied text looks like:

```
There is no lag, data is synced up,
CD_EVENT was synced at: "YYYY-MM-DD hh:mm AM/PM"
```

## Files

- `index.html`: markup
- `styles.css`: styling
- `app.js`: real-time New York timestamp + copy logic
